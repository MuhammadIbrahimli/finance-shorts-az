# finance-shorts-az

Облачный конвейер коротких финансовых видео (9:16, 1080×1920, 24 fps) на азербайджанском языке для канала Disli Hardz. Раз в день его запускает облачная рутина по инструкции [prompt.md](prompt.md). Результат — видео и текст выдачи в Telegram. **Публикации нет.**

## Как устроено

```
find_trend ─► transcript ─► сценарий и выдача (пишет Claude) ─► tts ─► trim ─► align_words
          ─► раскадровка и сцена (пишет Claude) ─► render ─► QA-субагенты ─► notify
```

| Файл | Что делает |
|---|---|
| `prompt.md` | Пошаговая инструкция одного запуска рутины |
| `AGENTS.md` (+ `CLAUDE.md`) | Постоянные правила канала: формат, стиль, субтитры, проверка, выдача |
| `scripts/find_trend.py` | Самое просматриваемое финансовое Short ≤90 с, не старше 14 дней, не из `used.json` |
| `scripts/transcript.py` | Текст видео: сначала файл из vidIQ (его сохраняет Claude), иначе субтитры YouTube |
| `scripts/tts.py` | Озвучка сценария через Gemini TTS |
| `scripts/trim.py` | Паузы длиннее 0.4 с сокращаются до 0.2 с |
| `scripts/align_words.py` | Тайминги слов: распознавание озвучки (faster-whisper) и выравнивание по тексту сценария |
| `scripts/render.py` | Снимает сцену `window.renderAt(t)` кадр за кадром через Chromium, собирает MP4 24 fps |
| `scripts/notify.py` | Отправляет видео и блок выдачи в Telegram; при ошибке шлёт отчёт |
| `templates/scene_template.html` | Каркас сцены и вшитые караоке-субтитры по спецификации |
| `.claude/agents/` | Три субагента проверки: `video-quality-reviewer`, `art-director`, `subtitle-auditor` |
| `.claude/skills/vizavi-motion/` | Скилл motion-роликов (применяется там, где не противоречит AGENTS.md) |
| `references/2d-video/` | Правила и образец контактного листа из 2D-проекта (ориентир стиля) |
| `tools/make_review_sheets.py` | Контактные листы и разности кадров для проверки |

## Настройка рутины (вручную, один раз)

1. Создайте облачную рутину: репозиторий `MuhammadIbrahimli/finance-shorts-az`, ветка `main`, расписание раз в день. Текст `prompt.md` — в промпт.
2. Setup script (Ubuntu):
   ```bash
   apt-get update && apt-get install -y ffmpeg
   pip install -r requirements.txt
   playwright install chromium --with-deps
   ```
3. Переменные окружения рутины (это секреты, задаются в её настройках, в репозиторий не попадают):

| Переменная | Назначение |
|---|---|
| `YOUTUBE_API_KEY` | YouTube Data API v3 |
| `GEMINI_API_KEY` | Gemini API (TTS) |
| `TG_TOKEN` | токен бота Telegram |
| `TG_CHAT_ID` | id чата, куда бот отправляет результат |
| `GEMINI_TTS_MODEL`, `GEMINI_TTS_VOICE` | необязательно (по умолчанию `gemini-2.5-flash-preview-tts`, `Kore`) |
| `WHISPER_MODEL` | необязательно (по умолчанию `medium`) |

4. Доступ рутины на запись в `main` нужен только для коммита `used.json`.
5. vidIQ (необязательно): подключите коннектор к рутине.

## Локальная проверка

Ключи для локальной отладки лежат в файле вне репозитория. Путь задаётся переменной `FINANCE_SHORTS_ENV`. Шаблон без значений: [.env.example](.env.example). Файлы `.env`, `*.env` и `work/` в `.gitignore`.

```bash
pip install -r requirements.txt && playwright install chromium
python scripts/find_trend.py --dry-run     # только показать выбор, used.json не меняется
python scripts/notify.py --check           # проверка токена и чата, сообщения не отправляются
```

## Известные ограничения

- **Субтитры YouTube** читаются библиотекой `youtube-transcript-api` без ключа. Это неофициальный способ, и YouTube часто блокирует облачные IP. Надёжнее подключённый vidIQ.
- **Чат Telegram:** бот не может писать в чат, пока пользователь не нажмёт «Start» в диалоге с ботом.
- **`used.json`** помечает видео сразу при выборе, даже если последующие шаги упали.
- **Озвучка Gemini** на азербайджанском официально в документации не подтверждена. Проверяйте первый результат.
- **Музыки нет** (правило канала). Скилл `vizavi-motion` её предлагает по умолчанию, здесь это переопределено.
- **Лимит Telegram** — 50 МБ. Видео 30–60 с при CRF 22 обычно укладывается.
- **Конфликт правил:** AGENTS.md запрещает обрезать голос пользователя, но конвейер по требованию владельца сокращает паузы в синтезированной озвучке. Это единственная обрезка, текст и скорость не меняются.
- **Что не перенесено:** папка `Daxilde/` (другой канал), скилл `script-rewrite` (относится к каналу «Дахилде»), 3D-проекты, сами видео и медиа проектов. Файлы `STORYBOARD.md` и `config.json`, на которые ссылались правила, в исходной папке не существовали.
