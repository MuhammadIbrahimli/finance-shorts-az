# Image Continuity for a Recurring Character

When consistent images are needed, use a source-reference/editing workflow for one character, object, or scene. For a permitted route, see [conditional image providers](image-providers.md). Preserve identity, proportions, construction, style, lighting, and anchor details; change only the requested pose, position, angle, or action phase. For every new pose, provide the same canonical reference set, not only the latest regenerated image with accumulated drift. Do not make each successive frame an independent lookalike without anchoring it to the source.

Before generation, record persistent features, camera/shot size, anchors, scale, light source, background/alpha, and what changes in each phase. Afterwards, align anchor points, silhouette, and contact; inspect face/anatomy, hands, object details, perspective, and light direction. State the actual intervals in the video when each state appears. The task determines the number of poses: old local requirements for three or five poses are not universal.

Three poses changing in sequence are discrete states, not a complete smooth rotation. Cropping, zooming, interpolation, or 2.5D parallax on one image is not a new pose or a free 3D camera. Smooth transitions require sufficiently consistent intermediate states or real geometry; choose a method for the task and describe the result honestly. Do not call a morph of incorrect anatomy smooth motion.

For transparency, create a real PNG with an alpha channel. A drawn checkerboard or flat background is not transparency. Check the alpha channel, edges on dark and light backgrounds, color fringes, and premultiplied alpha. Export and scaling must not restore a baked-in background or jagged edges.

If an image is used in motion, give it a role in the action: character, contact object, spatial layer, material, or participant in a transformation. Tie movement to the storyboard. A simple camera move across a passive image does not replace the promised action. Layers and painted-in hidden areas must withstand the selected camera; do not promise a truthful new viewpoint when the source lacks that information.
