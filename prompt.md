# Ежедневный запуск: короткое финансовое видео на азербайджанском

Ты работаешь в клоне репозитория `finance-shorts-az` в облачной рутине. Ты один раз запускаешь конвейер. Публиковать видео где-либо **нельзя**. Результат отправляется только в Telegram. Не используй чужие видео как есть: ни кадры, ни звук, ни текст целиком. Используй только факты и идеи, переписанные своими словами.

## 0. Подготовка окружения

```bash
pip install -r requirements.txt
playwright install chromium --with-deps
which ffmpeg ffprobe || echo "NO FFMPEG"
```

Если `ffmpeg` нет, сразу отправь отчёт об ошибке (см. «Ошибки») и остановись.

Переменные окружения: `YOUTUBE_API_KEY`, `GEMINI_API_KEY`, `TG_TOKEN`, `TG_CHAT_ID`. Не выводи их значения в лог и не записывай в файлы.

Дизайн сцены делай по скиллу `.claude/skills/vizavi-motion/SKILL.md`. Он в репозитории. Шаблон сцены: `templates/scene_template.html`.

Все промежуточные файлы лежат в `work/`. Эта папка не коммитится.

## Общий порядок

Выполняй шаги по порядку. Если шаг упал, сразу выполни `python scripts/notify.py --error --step "<имя шага>" --message "<краткая причина>"` и остановись. Не продолжай дальше.

## 1. Поиск тренда

```bash
python scripts/find_trend.py
```

Скрипт выбирает самое просматриваемое финансовое Short-видео не старше 14 дней (не длиннее 90 с), которого нет в `used.json`. Записывает его в `work/trend.json` и добавляет его id в `used.json`.

## 2. Транскрипт

Сначала проверь, подключён ли коннектор vidIQ, и есть ли у него инструмент `video_transcript`.

- Если да: вызови `video_transcript` для ссылки из `work/trend.json` (поле `url`). Сохрани только чистый текст без таймкодов в файл `work/vidiq_transcript.txt`.
- Затем выполни:

```bash
python scripts/transcript.py
```

Скрипт использует `work/vidiq_transcript.txt`, если он есть. Иначе он берёт субтитры YouTube. YouTube может блокировать облачные IP. В этом случае скрипт завершится с ошибкой, и ты отправляешь отчёт об ошибке.

Если транскрипт пустой или очень короткий (меньше 300 символов), это ошибка. Не придумывай текст сам.

## 3. Перевод и сценарий (пишешь ты)

Прочитай `work/transcript.txt` и `work/trend.json`. Напиши `work/script.json` в таком виде:

```json
{
  "title_az": "до 90 символов, по-азербайджански",
  "description_az": "2–4 предложения и короткая строка: «Bu video maliyyə məsləhəti deyil.»",
  "narration_az": "текст озвучки, примерно 90–130 слов, 30–50 секунд",
  "cover_prompt": "промпт обложки на английском для генератора изображений, 9:16",
  "key_facts": ["факт или число из источника, которые ты сохранил"]
}
```

Правила перевода и сценария:

- Передавай смысл, факты и цифры точно. Числа, проценты, даты и единицы не меняй.
- Формулировки пиши свои. Не копируй предложения и не переводи дословно. Структуру идеи можно сохранить, текст должен быть новым.
- Если в источнике утверждение нельзя проверить, так и пиши: «по данным источника» или не включай его.
- Не давай персональных инвестиционных рекомендаций. Не называй конкретные акции или криптовалюты как «покупайте».
- Пиши естественным азербайджанским языком: используй ə, ı, ö, ü, ş, ç, ğ правильно.

## 4. Озвучка

```bash
python scripts/tts.py
```

Скрипт использует Gemini TTS и `narration_az` из `work/script.json`. Результат: `work/narration.wav`.

## 5. Обрезка тишины

```bash
python scripts/trim.py
```

Тишина длиннее 0.4 с сокращается до 0.2 с. Результат: `work/narration_trim.wav`. Проверь длительность в выводе. Если она меньше 20 с или больше 60 с, перепиши `narration_az` и повтори шаги 4–5.

## 6. Сцена

Длительность сцены должна равняться длительности `work/narration_trim.wav`. Узнай её так:

```bash
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 work/narration_trim.wav
```

Напиши `work/scene/index.html` по `templates/scene_template.html`:

- `window.DURATION_SEC` равен длительности озвучки, округлённой до сотых.
- `window.setTime(t)` рисует кадр в момент `t` и не зависит от состояния предыдущих кадров.
- Размер 1080×1920 (9:16, вертикальный формат Shorts).
- Текст на азербайджанском. Используй шрифт, который поддерживает латиницу с диакритикой.
- Сделай сцену по раскадровке из скилла `vizavi-motion`: камера, движение, типографика, ритм. Не добавляй внешние изображения и видео, которые не можешь получить по лицензии. Используй только векторные фигуры, CSS и текст.

Если в `assets/music.mp3` есть лицензированная музыка, `render.py` подмешает её автоматически. Не скачивай музыку сам.

## 7. Рендер

```bash
python scripts/render.py
```

Результат: `work/video.mp4` (1080×1920, H.264, AAC). Если рендер упал, прочитай ошибку, исправь сцену и повтори только этот шаг. Не больше двух повторов.

## 8. Отправка в Telegram

```bash
python scripts/notify.py
```

Скрипт отправит видео, название, описание, промпт обложки и ссылку на источник.

## 9. Сохранение used.json

`find_trend.py` уже обновил `used.json`. Закоммить и отправь в `main` только этот файл:

```bash
git config user.name "finance-shorts-bot"
git config user.email "finance-shorts-bot@users.noreply.github.com"
git add used.json
git commit -m "Mark video as used: <video_id из work/trend.json>"
git push origin HEAD:main
```

Не коммить `work/` и не создавай ветки или PR.

## Ошибки

Если любой шаг упал, сделай одно:

```bash
python scripts/notify.py --error --step "<номер и название шага>" --message "<что случилось, 1–3 предложения>"
```

Не выдавай заглушку за готовое видео. Если что-то не получилось, пиши об этом прямо.
